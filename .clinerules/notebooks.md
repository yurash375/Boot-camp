# Правила для ноутбуков

- Меняй только те ячейки, которых касается задача; порядок и содержимое остальных не трогай.
- Сохраняй формат материалов: markdown-заголовки `# Задание N` в домашках, русский язык описаний,
  существующие ссылки и формулировки условий.
- Плейсхолдеры `### YOUR CODE HERE` не удаляй и не переписывай: их заполняет студент.
- Не выполняй ноутбук целиком и не обновляй `outputs`/`execution_count` без явного разрешения.
- После правки убедись, что ноутбук — валидный JSON:
  `python3 -c "import json; json.load(open('<путь к файлу.ipynb>'))"`.
- Если задача требует данных из `data/`, только читай их; создавать новые файлы данных можно лишь
  по явной просьбе, иначе предлагай вывод результата прямо в ячейке.
