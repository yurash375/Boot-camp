# Правила Cline для этого репозитория

Основные соглашения описаны в `AGENTS.md` в корне репозитория — выполняй их вместе с этими правилами.

## Режим работы

- Для задач, затрагивающих несколько файлов или ноутбуков, сначала предлагай план (Plan mode),
  и только после подтверждения переходи к правкам.
- Держи диффы минимальными: не переформатируй файлы, не переставляй ячейки, не «чисти» выводы
  ноутбуков и не удаляй неиспользуемые импорты, если об этом не просили.

## Границы изменений

- Изменения в `**/data/**`, `FILES/`, `Literature/` и в `HOMEWORK/hw.ipynb` выполняй только после
  явного согласования с пользователем.
- Домашние задания — для студента: не заполняй `### YOUR CODE HERE` и не выполняй ячейки в `HOMEWORK/`.
  По запросу давай подсказки, объяснения и разбор ошибок.
- Новые зависимости и файл `requirements.txt` не создавай без согласования.

## Проверка результата

- Перед правкой и после неё проверяй, что ноутбук остаётся валидным JSON:
  `python3 -c "import json; json.load(open('<путь к файлу.ipynb>'))"`.
- Скрипты из `code_examples/` проверяй запуском из папки урока: `python3 <файл>`.
- Ноутбуки целиком не выполняй; отдельные ячейки запускай только с явного разрешения
  (ячейки с `requests`/`pandas` могут обращаться к сети и к локальным данным).

## Git

- Ветка для работы агента — `cline/<id>`; в `master` напрямую не коммить.
- Коммить и пушить только по явной просьбе, сообщения — короткие, латиницей, в стиле репозитория
  (`lesson-8_add_more_examples`, `fixed hw lesson-7`).
