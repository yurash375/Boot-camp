# AGENTS.md — учебный курс по Python

Постоянные инструкции для AI-агентов (Cline, GitHub Copilot, Codex, Claude), которые работают
с этим репозиторием. Этот файл — единый источник соглашений: отдельные инструменты дополнительно
подхватывают `.clinerules/` и `.github/`.

## О репозитории

Учебный курс «Boot camp» по Python: 8 уроков, материалы и задания на русском языке.

```text
<N> lesson. <Тема урока>/
├── HOMEWORK/hw.ipynb      # домашнее задание для студента
├── code_examples/         # материалы лекции: lesson.ipynb, *.py
│   ├── data/              # входные данные примеров (csv, txt, xlsx, zip)
│   └── package/           # пример пакета (урок 8)
└── FILES/                 # pdf/docx с теорией
Literature/                # книги по Python
```

## Соглашения по коду

- Python 3.11; скрипты-примеры запускаются из папки своего урока.
- PEP 8: 4 пробела для отступов, `snake_case` для функций и переменных, латиница в идентификаторах.
- Комментарии и строки документации — по-русски (так написаны все материалы курса).
- Аннотации типов приветствуются: `def hello_name(name: str) -> str:`.
- Библиотеки: в примерах используется преимущественно стандартная библиотека (`os`, `sys`, `json`,
  `csv`, `zipfile`, `datetime`, `dis`), из внешних встречаются `pandas`, `numpy`, `requests`, `chardet`.
- `requirements.txt`, тестов и линтеров в проекте нет. Новые зависимости не добавляй без согласования,
  корректность подтверждай запуском (`python3 <файл>`) и показывай результат.

## Работа с ноутбуками (.ipynb)

- Лекции — `code_examples/lesson.ipynb` (много ячеек, сохранённые выводы), домашки — `HOMEWORK/hw.ipynb`.
- Правь только те ячейки, которых касается задача: минимальный дифф, без переформатирования JSON,
  без удаления и перестановки чужих ячеек.
- Не изменяй `outputs` и `execution_count` существующих ячеек без явной просьбы.
- В `HOMEWORK/hw.ipynb` есть плейсхолдеры `### YOUR CODE HERE` — это задания студента: не решай их
  и не выполняй ячейки, если об этом не попросили прямо.
- Сохраняй структуру материалов: markdown-заголовки вида `# Задание N`, ссылки и формулировки задач.

## Что нельзя делать

- Изменять или удалять файлы данных: `**/data/**`, `**/*.csv`, `**/*.xlsx`, `**/*.zip`,
  а также `1 lesson. Intro/code_examples/experiment_for_os/**` — это результаты экспериментов с файловой системой.
- Перезаписывать учебные материалы в `FILES/` и `Literature/` (pdf, docx, книги).
- Менять git-историю (`rebase`, `reset --hard`, force-push) и удалять ветки.
- Коммитить и пушить без явной просьбы. Секреты, ключи и токены в репозиторий не попадают никогда.

## Рабочий процесс

1. Сначала посмотри аналогичный пример в соседнем уроке и повтори его стиль.
2. Небольшие правки — сразу; задачи на несколько файлов или ноутбуков — сначала план, потом правки.
3. После изменений перечисли затронутые файлы и способ проверки результата.
4. Сообщения коммитов — короткие, латиницей, в стиле репозитория:
   `lesson-8_add_more_examples`, `fixed hw lesson-7`.

## Формат ответов

- Общение и комментарии в коде — по-русски; код, имена файлов и идентификаторы — латиницей.
- Если условие задачи допускает разные трактовки — задай вопрос, а не додумывай требования.
